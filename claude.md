# Halo

Halo is a macOS-first focus app: a Session-style Pomodoro timer, daily planner, distraction blocker, and a trading-discipline desk. It's a desktop app built with **Tauri v2** (Rust core) and a **TypeScript** UI. The goal is one thing: more deep work, less drift.

- Owner: 0xOse (Seraph Labz)
- Status: phases 1–2 done (timer, Focus screen, menu bar, popover, mini timer, check-ins, break overlay, palette); phase 3 next
- Design canvas (source of truth for UI): https://claude.ai/artifact/6KUBniDhU2wna5WumwFeqf

## Product scope (v1)

**Timer**
- Presets: Pomodoro 25/5, Deep 50/10, custom; long break every N rounds
- Flowtime mode (stopwatch; earned break ≈ elapsed / 5)
- Overflow: the timer keeps counting past the goal
- Intention prompt before every session
- Mid-session check-ins ("Still on it?" Yes / I drifted)
- Auto-start next phase, pause limit per session, manual log for missed sessions

**Planning**
- Tasks with session estimates, projects with colors, subtasks, recurring tasks
- Today plan with a time-block timeline
- Natural-language quick add ("review PR tomorrow 10am ~2 sessions #meridian-rs")
- Session notes
- Google Calendar sync; import from GitHub, Linear, and Notion

**Shield (blocking)**
- Website and app blocking, blocklist or allowlist-only mode
- Strict mode: can't end, pause, or disable until the session ends
- Auto Do Not Disturb, idle auto-pause, distraction counter

**Ambience and breaks**
- Ambient sounds and lo-fi, fullscreen zen mode
- Guided breaks, break overlay on every display

**Stats**
- Post-session rating, daily and weekly reports, heatmap, peak hours, time per project, focus score, CSV/JSON export

**Motivation**
- Streaks, daily goal ring, achievements, something that grows while you focus

**Desktop**
- Menu bar timer and popover, floating always-on-top mini timer
- Global hotkeys, ⌘K command palette
- Offline-first local SQLite, synced to Supabase when signed in; native notifications

**Trading desk**
- Session clocks: Sydney, Tokyo, London, New York, shown in the user's time zone with live countdowns
- Pre-trade checklist
- Head check: 1–5 "how clear is your head" before trading
- Chart time outside the trading window

**Later (v2)**
- AI daily planner, AI task breakdown, AI weekly review
- CLI and webhooks

## Stack

Scaffolded 2026-11-21.

- **Repo:** pnpm workspace (`apps/*`, `packages/*`) plus a Cargo workspace (`apps/desktop/src-tauri`, `crates/*`), same shape as pewterdesk. One `target/` at the root.
- **Shell:** Tauri v2 (`com.seraphlabz.halo`, macOS 13+)
- **Core (Rust, edition 2024):**
  - `tokio` for the timer engine
  - `rusqlite` 0.43 (bundled SQLite) with a small in-house `PRAGMA user_version` migration runner in `crates/store`
  - `serde`, plus `chrono` and `chrono-tz` for time
  - `thiserror` for errors (`error::Error` internally, `error::IpcError` over IPC)
  - `objc2` crates for macOS APIs (add when the first macOS feature needs them)
  - Clippy denies `unwrap_used` and `expect_used` (allowed in tests) via `[workspace.lints]` in the root `Cargo.toml`
- **UI:** TypeScript (strict), React 19 and Vite, Zustand for UI state, Tailwind v4. `packages/ui/src/styles/tokens.css` is a copy of `design/tokens.css`; `packages/ui/src/styles/global.css` (imported as `@halo/ui/styles.css`) maps it to Tailwind (`bg-focus`, `text-text-secondary`, `rounded-card`, `glass`, ...). Inter is bundled via `@fontsource-variable/inter` (offline-first).
- **IPC:** typed Tauri commands via `tauri-specta` (`=2.0.0-rc.29`, with `specta =2.0.0-rc.28`; keep the `=` pins). `packages/core/src/bindings.ts` (exported from `@halo/core`) is generated by `cargo test` and on every debug run. Never edit it by hand. Commands use `ErrorHandlingMode::Result`, so they resolve to `{ status: "ok", data } | { status: "error", error }`; unwrap them in `features/*/api.ts`.
- **Tauri plugins:** global-shortcut, notification, autostart. The DB lives in Rust, not in `plugin-sql`.
- **Tests:** `cargo test` for Rust; Vitest + Testing Library (jsdom) for UI.
- **Package manager:** pnpm
- **Git hooks:** `pnpm install` runs `prepare`, which sets `core.hooksPath` to `.githooks`. Opt out with `pnpm hooks:uninstall`.
- **CI:** `.github/workflows/ci.yml` fails if `packages/core/src/bindings.ts` is stale. Run `cargo test` and commit the regenerated file.

### Adding a command

1. Write it in `apps/desktop/src-tauri/src/commands/<area>.rs` with `#[tauri::command]` and `#[specta::specta]`, returning `Result<T, IpcError>`. Logic belongs in a crate; the command only calls it.
2. Register it in `specta_builder()` in `apps/desktop/src-tauri/src/lib.rs` (`collect_commands![...]`). Events go in `collect_events![...]`.
3. Run `cargo test` to regenerate `packages/core/src/bindings.ts`.
4. Wrap it in `apps/desktop/src/features/<area>/api.ts`, importing from `@halo/core`.

### Adding a migration

Add `crates/store/migrations/NNNN_name.sql` and append `include_str!("../migrations/NNNN_name.sql")` to `MIGRATIONS` in `crates/store/src/lib.rs`. The DB is `halo.db` in the app data dir (`~/Library/Application Support/com.seraphlabz.halo/`).

## Architecture

- **Rust owns state and time.** The timer engine runs in Rust and emits events (`timer://tick`, `timer://phase`). Every window renders from those events, so the main window, menu bar, mini timer and overlays never disagree.
- **The UI is a view.** UI code never computes session time. It calls commands and renders events.
- **Windows:**
  - `main`
  - `tray-popover`: borderless, placed under the tray icon, hides on blur
  - `mini`: always on top, transparent, draggable
  - `break-overlay`: one per display
  - `palette`: ⌘K
- **Menu bar:** use the tray icon title on macOS for the countdown text. Monochrome template icon by default.
- **Storage:** a SQLite file in the app data dir is the source of truth; the app works fully offline. Every schema change is a numbered migration. Never edit an applied migration.
- **Cloud sync (Supabase):** when the user signs in, sessions and settings sync to Supabase Postgres (`supabase/`). Rows have UUID text ids, `updated_at` (unix ms; newest wins), `deleted_at` (soft delete) and a local-only `synced_at` (NULL = needs upload). Every synced table change needs a local migration in `crates/store/migrations/` **and** a matching one in `supabase/migrations/` with row-level security. The app only ever holds the anon key, from `.env.cloud` at build time; never the service-role key.

## Domain model (starting point)

- `Session`: id, kind (pomodoro / deep / flowtime / custom), planned_secs, started_at, ended_at, overflow_secs, intention, project_id, task_id, strict, rating, distractions, notes
- `CheckIn`: session_id, at, response (focused / drifted)
- `Project`, `Task` (estimate_sessions, done_sessions, parent_id, recurrence), `TimeBlock`
- `ShieldRule`: kind (site / app), value, schedule (always / focus-only / outside-trading-window)
- `ChecklistItem`, `ChecklistRun`: date, item_id, checked_at
- `HeadCheck`: at, score 1–5, factors[]
- `ChartActivity`: app, host, started_at, ended_at, in_window

## Trading desk rules

- **Define sessions in their own time zone.** Use IANA zones and local hours, never fixed UTC offsets, so daylight saving is handled:
  - Sydney 09:00–18:00 `Australia/Sydney`
  - Tokyo 09:00–18:00 `Asia/Tokyo`
  - London 08:00–16:30 `Europe/London`
  - New York 09:30–16:00 `America/New_York`
- **Display in the user's zone.** Default `Africa/Lagos`.
- **Weekend:** FX sessions close from Friday's New York close to Sunday's Sydney open. Crypto trades 24/7, so the UI labels sessions as liquidity windows.
- **Trading window:** the user's window is configurable. Default: New York session, weekdays.
- **Unlock gate:** exchanges unlock only when the checklist is complete AND head check ≥ 3 AND the time is inside the window.
  - Score 1–2: locked for the rest of the day; suggest a focus block instead.
  - Score 3: show a "half size, max 2 trades" reminder.
- **Chart time:** charting apps and hosts (TradingView, Binance, DEX Screener; editable) are tracked. Time outside the window is counted. Nudge after 5 minutes (setting).
- **Hard line:** Halo never places trades, never holds exchange API keys, and never gives trading advice. It only manages time, attention and the user's own rules.
- **Tests:** session-clock math needs unit tests for DST switch days, weekend boundaries, and windows that cross midnight.

## macOS hard parts

Write a short ADR for each of these before building it.

- **Website blocking:** must survive app quit in strict mode, so it's enforced outside the UI process. Options: a privileged helper editing `/etc/hosts` (registered via `SMAppService`), a Network Extension (Swift), or a companion browser extension.
- **App blocking:** watch launches with `NSWorkspace` notifications and terminate blocked apps. Allow a grace notice.
- **Frontmost app and URL (chart time):** frontmost app comes from `NSWorkspace`. Browser URL needs AppleScript, which requires Automation permission. Explain permissions in onboarding.
- **Idle detection:** `CGEventSourceSecondsSinceLastEventType`.
- **Do Not Disturb:** there's no public API. Trigger a user-installed Shortcut (`shortcuts run "Halo Focus On"`).
- **Permissions:** never assume a permission is granted. Every blocked capability degrades with a clear in-app explanation.

## Conventions

- **Rust:**
  - `cargo fmt`; `cargo clippy -- -D warnings`
  - No `unwrap`/`expect` outside tests
  - Errors via `thiserror`, mapped to typed IPC errors
- **TypeScript:**
  - `strict: true`; no `any`
  - ESLint and Prettier
  - Components stay presentational; IPC calls live in `features/*/api.ts`
- **Tests:**
  - Timer engine and trading clock math are pure and fully unit-tested.
  - UI gets smoke tests for each window.
- **Commits:** Conventional Commits (`feat(timer): overflow mode`). Small PRs, one feature each.
- **Copy:** short, verb-first, no "successfully", no exclamation marks in system text.
